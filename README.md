# Thaka Platformer

A short 2.5D platformer built in Unity for the Thaka International Unity developer task.
One level of about 2–3 minutes: run, jump, stomp enemies, collect coins and reach the flag.
Progress is saved at checkpoints and Continue picks up where you left off.

## Download

A Windows build is available on the [Releases](https://github.com/Youssefsayed88/ThakaPlatformer/releases) page.
Unzip it and run `Thaka Platformer.exe`.

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | A / D or ← / → | Left stick or D-pad |
| Jump | Space, W or ↑ | South button |
| Pause | Esc | Start |

Land on enemies to stomp them. Touching them from the side costs 1 of your 4 HP.

## Opening the project

- Unity **6000.0.67f1** (URP)
- Open `Assets/_Project/Scenes/MainMenu` and press Play
- Tests: *Thaka → Tests* in the editor menu
